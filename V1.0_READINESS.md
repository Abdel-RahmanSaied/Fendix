   `COSIGN_ENABLED=true` repo variable and stand up `get.fendix.dev` DNS, then

   tag. Requires repo-admin + DNS access.

2. **Open-source license + announcement (TASK-112) — a business/legal call.**
   The README already declares MIT + ADR-007, but the actual repo-split decision
   (what, if anything, stays private), license finalization, and launch
   communication are an owner decision, not an agent's.

3. **Java-parser architecture decision — gates deep Java taint + any real OWASP
   number (post-v1.0 capability, not a v1.0 blocker, but the standing fork).**
   CGo tree-sitter breaks the single-static-binary invariant; WASM-via-wazero or
   javalang-on-Python are the non-breaking options. Until the operator chooses,
   OWASP stays SKIP and no Java/OWASP accuracy number ships. See
   `benchmarks/targets/owasp-known.json` `_definition_of_done`.
