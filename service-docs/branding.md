# Fendix — Brand & Logo Design Brief

## Brand Positioning

**Fendix** = "Fend" (to defend) + "ix" (tech suffix) — a tool that **defends** code and APIs from security threats.

**Tagline options:**
- "Find vulnerabilities before attackers do"
- "Defend your APIs. Secure your code."
- "Hybrid security scanning, elevated confidence"

---

## Brand Personality

| Trait | What It Means |
|-------|--------------|
| **Trustworthy** | Security product — must feel solid, reliable, professional |
| **Technical** | Developer-first tool — not corporate fluff |
| **Sharp** | Finds things others miss — precision, not noise |
| **Modern** | CLI-native, CI/CD-integrated — not legacy enterprise |
| **Confident** | Not aggressive or fear-based — calm authority |

**Tone:** Think "senior engineer who spots the bug in code review" — not "alarm system screaming at you."

---

## Logo Direction

### Concept 1 — Shield + Code
A minimal shield shape with a code element inside (bracket `< >`, slash `/`, or terminal cursor `_`). Represents protection of code.

### Concept 2 — Scan Line
The letter "F" integrated with a horizontal scan line or radar sweep. Represents the scanning/detection function.

### Concept 3 — Dual Lens
Two overlapping circles or lens shapes (representing black-box + white-box) merging into one. The overlap area is highlighted — representing the "correlated" finding (Fendix's differentiator).

### Concept 4 — Lock + Terminal
A padlock icon where the keyhole is shaped like a terminal prompt `>_`. Security meets developer tooling.

### Requirements
- Must work as a **monochrome icon** (CLI output, terminal, favicon)
- Must work at **16x16px** (favicon) and on a **t-shirt**
- No gradients in the primary mark — flat/geometric
- Should work on both dark and light backgrounds
- Wordmark "FENDIX" should be a clean sans-serif (Inter, JetBrains Mono, or similar)

## Color Palette

| Role | Color | Hex | Why |
|------|-------|-----|-----|
| **Primary** | Deep indigo/navy | `#1E293B` | Trust, depth, professionalism |
| **Accent** | Electric cyan or teal | `#06B6D4` | Scanning/detection energy, tech feel |
| **Alert** | Signal red | `#DC2626` | Critical findings (already used in HTML reports) |
| **Warning** | Amber | `#D97706` | Medium findings |
| **Success** | Green | `#16A34A` | Clean scan, passing CI |
| **Neutral** | Slate gray | `#475569` | Body text, secondary info |

The primary + accent pair should carry 90% of the brand. Red/amber/green only appear in scan results context.

## Typography

| Use | Font | Why |
|-----|------|-----|
| **Logo wordmark** | JetBrains Mono or Space Grotesk | Monospace = developer tool identity |
| **Headings** | Inter or DM Sans | Clean, modern, excellent readability |
| **Code/CLI** | JetBrains Mono | Industry standard for terminals |

---

## Usage Guidelines

### Do
- Use the icon alone for small contexts (favicon, CLI, GitHub avatar)
- Use icon + wordmark for docs, website, slides
- Maintain clear space around the logo (minimum = height of the "F")
- Use monochrome version on busy backgrounds

### Don't
- Don't rotate or skew the logo
- Don't add drop shadows or 3D effects
- Don't place on low-contrast backgrounds
- Don't use the alert colors (red/amber) in the logo itself
- Don't stretch or distort proportions
