## The governing invariant (from scoping)

Reporters marshal `reporters.JSONReport` whose `Findings` field is
`[]models.Finding` **serialized directly** (`go/internal/reporters/json.go:87-94`).
Therefore **`models.Finding`'s struct tags ARE the public JSON/SARIF/HTML
contract.** Every v0.22 change must leave `Finding`'s serialization
byte-identical. Guards: `go/tests/regression/output_format` snapshots,
`reporters/schema_test.go` (validates `docs/schema.md`), `reporters/{json,sarif,html}_test.go`.

## Current flow (what we're layering under)
`scanners → []Finding → Correlate() (correlator.go) → escalate → Deduplicate()
→ enforceConsistency → sort → assign ID/fingerprint → ignore/baseline → reporters`
Decision today = `checkFailOn()` severity→exit-code (`orchestrator.go:803-820`).

## Already present (do NOT rebuild — Rule 1)

## Genuinely new (the v0.22 work)
- **Evidence domain model** capturing what's missing: source engine, rule/check id, location, **raw payload + response**, metadata, timestamp, confidence — plus correlation **lineage** (which BB+WB evidence merged).
- **Evidence interfaces + backward-compat adapters** (Finding ⇄ Evidence) so reporters keep emitting today's `Finding` JSON.
- **Correlation Service V2** operating on Evidence (normalize, dedup, cross-engine match, confidence inputs, aggregation) — wrapping/replacing `Correlate()` behind the same output.
- **Internal Decision object** (`BLOCK / WARN / INFO / IGNORE` + confidence + reason + supporting evidence) — NOT serialized/exposed in v0.22.
- **Migration + regression tests**; correlation coverage > 80%.
